# PhaseFlow Config Index

This directory contains the final paper-facing configuration summaries only.

- `final_llps.yaml`: final full-length LLPS model configuration, data summary,
  checkpoint identity, and reported LLPS metrics.
- `final_dpr.yaml`: final DPR fine-tuning, selection, post-processing, and
  benchmark configuration for the reported PhaseFlow model.

The raw resolved runtime config for the final DPR checkpoint is stored at
`artifacts/model/configs/resolved_finetune_config.json`.
